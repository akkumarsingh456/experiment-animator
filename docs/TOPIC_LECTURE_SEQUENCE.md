# Per-topic lecture sequence

## Requested display order

For each existing topic, reuse its supplied content in this sequence:

1. Activity or experiment, including its materials, procedure and observations.
2. Topic explanation, definitions and background notes.
3. Important points, properties, limitations and exceptions.
4. Formulas with the corresponding available derivations, symbols, units and conditions.
5. Uses and applications.
6. Additional examples, practice, answers, revision and source-review material.

An absent activity or proof is not generated or replaced with filler. Multiple existing activities and repeated supplied lines are retained. Topic/chapter slide order, original PDF pages, diagrams, reaction mechanisms, code, tables and complete proof/procedure step sequences remain intact. Qualifiers stay with the preceding original statement; separately stored proofs are paired only by the same written relation. Unknown associations are not invented.

## Integration and preservation

The ordering step runs after generation, before existing PPT pagination, and on the existing guided-topic groups. It uses the existing slide cards, formula tables, derivation renderer, visual components and exports. It does not change models, prompts, retrieval, source records, saved lesson data, educational wording or the view-only verification report. Guided notes retain per-topic entries rather than suppressing a repeated explanation in a later topic.

The tests compare complete input/output line multisets, including duplicates, and verify activity/notes/important-points/formula-proof/use order, matching proofs, conditions, original source rows, code/diagram/procedure preservation, no invented missing components, separate topic cycles and current pagination across 189 configured chapter fixtures. These checks verify arrangement and retention, not factual correctness of every saved lesson.

## Live saved-data retention check

A read-only check of 231 accessible cached lessons tested the ordering step on 1,518 existing topic records containing 40,410 supplied section lines. Every line and duplicate was retained, with zero missing/changed rows and no changes to the stored input. This certifies retention through the new ordering step, not independent scientific correctness. The optional repeatable check is EDUPLAN_LIVE_TOPIC_SEQUENCE=1 with tests/live-topic-sequence.test.ts.
