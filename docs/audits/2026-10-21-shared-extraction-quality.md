# Shared extraction quality correction

The periodic-table screenshot exposed two shared gaps: source-review entries bypassed note cleaning, and copied PDF damage could pass word-overlap verification because the same damaged tokens occurred in the source.

The correction applies structural checks to flattened prose across chapter generation, topic completeness, final verification and affected cached lessons. It detects multiple table labels mixed with numeric entries without sentence structure, alongside the existing page-header and fragment checks. Properly delimited tables, code, authored mathematics and readable explanations are preserved.

Detected original entries remain available in source review, separate from verified explanations. They cannot satisfy the topic's minimum evidence requirement. Fresh generation and affected cached topics use the existing scoped NCERT recovery path when surviving notes are insufficient. The 401-topic external supplementation allowlist is unchanged. Original teacher PDFs, language source passages, adequate notes, image editing, saving/sharing and navigation are not redesigned.
