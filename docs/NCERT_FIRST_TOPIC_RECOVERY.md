# NCERT-first recovery for incomplete topic notes

## Rules

- Keep adequately sourced notes unchanged. Run recovery only when a content
  topic has fewer than three substantive statements or under 240 characters
  of explanation. This threshold is a completeness heuristic, not a truth test.
- Try three distinct extraction strategies on already chapter-scoped uploaded
  NCERT sources, including alternate matching uploads: numbered sections and
  aliases; unnumbered named subsections; topic-specific paragraph matching.
  Stop as soon as sufficient evidence is recovered. No repeated filler.
- Preserve source wording, existing useful notes and authored formulas. Remove
  obsolete missing-source notices only when a replacement explanation exists.
  Do not reconstruct damaged equations or flattened table correspondences.
- If uploaded NCERT recovery fails, try an exact chapter in the selected class
  and subject on IIT Kanpur's public SATHEE NCERT mirror. Supported discovery
  routes cover Science (9–10) and senior Physics/Chemistry/Mathematics where a
  matching index is available. Require an exact chapter title and same-origin
  chapter link. Do not use arbitrary websites, snippets or ungrounded AI facts.
- Mark external recovery explicitly in the slide footer and guided notes, with
  the source URL. The mirror may use older chapter numbers; match chapter titles
  and retain the website's selected class and current catalog.
- If recovery still fails, or final verification leaves a topic inadequate,
  return a specific source error and do not save a blank/incomplete lesson.
  A network failure is never permission to invent a scientifically plausible
  replacement. Languages and full-chapter transcription retain their existing
  workflow. Notes already saved/downloaded are not rewritten automatically.

## Reported preparation topic

`Preparation of KMnO4 and K2Cr2O7` maps to the textbook's unnumbered
`Potassium dichromate` and `Potassium permanganate` sections. Local inspection
of the official NCERT Chemistry chapter recovered 32 statement candidates in
the second strategy; the downloaded SATHEE mirror recovered 40 in the second
strategy. These are extraction counts, not a factual certification of each
candidate or the final generated lesson.

Verified source endpoint:
https://sathee.iitk.ac.in/sathee-neet/ncert-books/neet-ncert-books/neet-nb-che-12/chem-12-unit-8-the-d-and-f-block-elements/

Focused checks cover missing headings, three-pass exhaustion, no changes to
adequate notes, retention of existing facts, trusted chapter matching, HTML
cleanup, source failure without a blank saved lesson, and shared notes/export
safeguards. Neither lexical grounding nor valid notation guarantees 100%
factual accuracy. Publication and fresh generation are required to activate
the new non-language v66 generation cache.
